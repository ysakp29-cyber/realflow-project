# REALFLOW AI BUSINESS

릴플로 쿠팡 셀러용 통합 AI 운영 시스템.

## 목표
- 광고: 쿠팡 광고 CSV 업로드, ROAS/ACOS/CPC/전환율 분석, 예산/입찰 변경 제안 및 승인 기록
- 상세페이지: 상품 사진과 사양 입력, 10섹션 모바일 상세페이지 문구/레이아웃 초안, 이미지 원본 보존 및 검수
- 상품등록: 상품명, 검색 키워드, 옵션, 가격, 필수 고시정보 초안과 검증, CSV 내보내기
- 손익: 매출, 원가, 배송/플랫폼 수수료, 광고비, 반품비를 반영한 SKU별 이익
- 재고: 재고 부족 및 발주 추천
- 콘텐츠: 숏츠/릴스/틱톡 대본, 제목, 해시태그

## 권장 구현
Next.js + TypeScript + Tailwind, PostgreSQL, 인증, 파일 스토리지, 서버측 AI API. 비밀키는 환경변수에만 저장. 광고/등록 API는 공식 접근 권한 검증 후 구현.

## 개발 단계
1. 로그인, 제품/SKU 데이터 모델, 샘플 대시보드
2. 광고 CSV 업로드/지표 분석/변경 승인
3. 상세페이지 생성 및 미리보기/다운로드
4. 상품등록 초안/필수값 검증/내보내기
5. 손익·재고·콘텐츠 모듈
6. 공식 API 연동 및 작업 스케줄러

## 안전한 자동화 원칙
- 광고비, 가격, 상품게시 변경은 사용자 승인 후 실행
- 공식 API와 권한 범위 외의 우회 자동화 금지
- 수익 추정과 실제 정산 데이터 구분
- 이미지 생성 시 실물 제품의 구조/색상/구성 임의 변경 금지
- 모든 외부 변경에 감사 로그 및 실패 복구 제공

## 실행 가능한 광고 관리 MVP (2026-10-30)

첫 단계 광고 관리 화면을 구현했습니다. 위의 통합 운영 시스템 계획은 향후 로드맵이며, 현재 구현 범위는 아래 기능입니다.

### 실행 방법

Node.js 20 이상을 설치하고 저장소를 다운로드한 뒤 터미널에서 실행합니다. 외부 패키지 설치는 필요 없습니다.

```bash
git clone https://github.com/ysakp29-cyber/realflow-project.git
cd realflow-project
npm start
```

브라우저에서 **http://localhost:8000** 을 엽니다. 종료는 터미널에서 Ctrl+C. `index.html`을 더블클릭하면 ES 모듈 보안 제한으로 동작하지 않을 수 있으므로 HTTP 서버로 실행하세요.

### 사용 방법

1. 처음에는 3개 상품, 14일간의 예시 실적 42건이 표시됩니다. 실제 판매 성과가 아닙니다.
2. `실제 데이터 새로 시작`을 누르거나 CSV를 `현재 데이터 교체` 방식으로 가져옵니다.
3. 날짜·상품·키워드별 광고비, 광고 기여 매출, 노출수, 클릭수, 주문수를 입력합니다.
4. 기간·상품·키워드 필터로 조회하고 상품별/키워드별 성과표를 전환합니다.
5. 목표 ROAS를 설정하고 개선 제안을 확인합니다. 제안은 클릭 30회 기준과 목표 ROAS를 사용하는 **규칙 기반 분석**이며 외부 AI 모델을 호출하지 않습니다.
6. `데이터 내보내기`는 필터와 관계없이 전체 원본 데이터를 CSV로 백업합니다.

### CSV 형식

화면의 양식 다운로드를 사용하세요. UTF-8 인코딩, 최대 2MB. 영어 또는 아래 한국어 헤더가 가능합니다.

| 영어 | 한국어 | 값 |
| --- | --- | --- |
| date | 날짜 | YYYY-MM-DD |
| product | 상품명 | 필수 텍스트 |
| keyword | 키워드 | 필수 텍스트 |
| spend | 광고비 | 0 이상 금액 |
| revenue | 광고매출 | 0 이상 광고 기여 매출 |
| impressions | 노출수 | 0 이상 정수 |
| clicks | 클릭수 | 0 이상 정수, 노출수 이하 |
| orders | 주문수 | 0 이상 정수 |

쉼표 포함 값은 큰따옴표로 감쌉니다. 잘못된 행은 행 번호를 표시하고 전체 가져오기를 취소합니다. 추가 모드에서는 중복도 별도 실적으로 더해지므로 같은 파일을 반복 업로드하지 마세요. 예시와 실제 실적의 혼합 추가는 차단합니다. 쿠팡의 모든 보고서 형식을 자동 인식하지 않으므로 실제 파일은 양식에 맞춰 열을 정리해야 합니다.

### 지표 정의

- ROAS = 광고매출 / 광고비 × 100
- ACOS = 광고비 / 광고매출 × 100
- CTR = 클릭수 / 노출수 × 100
- CPC = 광고비 / 클릭수
- 전환율 = 주문수 / 클릭수 × 100

전체 지표는 원시 수치 합산 후 계산합니다. 분모가 0이면 `—`를 표시합니다. 금액은 화면에서 원 단위 반올림합니다. 주문수는 보고서의 주문 집계를 따르며 클릭수보다 많을 수도 있습니다.

### 저장 및 현재 한계

데이터는 현재 브라우저의 localStorage에만 저장됩니다. 로그인, 서버 DB, 기기간 동기화, 다중 사용자 공유는 없습니다. 브라우저 데이터 삭제 시 사라지므로 CSV 백업이 필요합니다. 저장 차단·용량 초과 시 안내를 표시합니다. 사이트에 외부 스크립트나 광고 계정/API 인증정보는 포함하지 않습니다.

개선 제안은 수익 보장이 아닙니다. 상품 마진·수수료·반품·전환 집계 지연·재고를 반영하지 않습니다. 실제 쿠팡 계정 연동, 입찰/예산 변경, 자동 집행은 구현하거나 수행하지 않았습니다. GitHub 코드 반영과 별도로 공개 호스팅 배포는 하지 않았습니다.

### 검증

```bash
npm test
node --check app.js
```

10개 자동 테스트 통과: 지표 계산, 0 분모, 가중 집계, CSV BOM/쉼표/따옴표/줄바꿈, 한국어 헤더, 잘못된 날짜·음수·빈 값·정수 검증, CSV 구조 오류, 제안 분기, CSV 수식 방지, 예시 데이터 검증.

브라우저에서 대시보드 최초 표시 및 키워드 필터(무타공 → 광고비 84,980원, 광고매출 0원) 동작을 확인했습니다. 실제 쿠팡 보고서 파일 및 실계정 연동 검증은 수행하지 않았습니다.
