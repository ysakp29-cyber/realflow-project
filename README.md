# REALFLOW AI BUSINESS

릴플로 쿠팡 셀러용 통합 AI 운영 시스템.

## 목표
- 광고: 쿠팡 광고 CSV 업로드, ROAS/ACOS/CPC/전환율 분석, 예산/입찰 변경 제안 및 승인 기록
- 상세페이지: 상품 사진과 사양 입력, 10섹션 모바일 상세페이지 문구/레이아웃 초안, 이미지 원본 보존 및 검수
- 상품등록: 상품명, 검색 키워드, 옵션, 가격, 필수 고시정보 초안과 검증, CSV 내보내기
- 손익: 매출, 원가, 배송/플랫폼 수수료, 광고비, 반품비를 반영한 SKU별 이익
- 재고: 재고 부족 및 발주 추천
- 콘텐츠: 숏츠/릴스/틱톡 대본, 제목, 해시태그

## 권장 구현
Next.js + TypeScript + Tailwind, PostgreSQL, 인증, 파일 스토리지, 서버측 AI API. 비밀키는 환경변수에만 저장. 광고/등록 API는 공식 접근 권한 검증 후 구현.

## 개발 단계
1. 로그인, 제품/SKU 데이터 모델, 샘플 대시보드
2. 광고 CSV 업로드/지표 분석/변경 승인
3. 상세페이지 생성 및 미리보기/다운로드
4. 상품등록 초안/필수값 검증/내보내기
5. 손익·재고·콘텐츠 모듈
6. 공식 API 연동 및 작업 스케줄러

## 안전한 자동화 원칙
- 광고비, 가격, 상품게시 변경은 사용자 승인 후 실행
- 공식 API와 권한 범위 외의 우회 자동화 금지
- 수익 추정과 실제 정산 데이터 구분
- 이미지 생성 시 실물 제품의 구조/색상/구성 임의 변경 금지
- 모든 외부 변경에 감사 로그 및 실패 복구 제공
